# Internationalization

The public site supports exactly two locales: `vi` and `en`. Vietnamese is the default.

Public URLs use a locale prefix. Route names are mapped in `src/i18n/config.ts`, including `/vi/dich-vu`, `/vi/du-an`, `/vi/bang-gia`, `/vi/lien-he` and their English equivalents. The language switcher maps the current route and preserves query parameters such as `service=business-website`.

All public copy is stored in `src/i18n/vi.ts` and `src/i18n/en.ts`. Components receive the selected dictionary from Server Components. Add a key to both files with the same structure.

Localized pages generate canonical URLs, `vi-VN`/`en` alternates, Open Graph and Twitter metadata. The sitemap includes both locale versions.
