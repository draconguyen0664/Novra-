## Section transitions

Header: full navigation disappears below 1200; compact logo, Orçamento CTA and two-line menu. Hero tablet image reaches viewport edges; mobile title aligns left, body 14px, 64px to a 121px wrapper with a larger overflowing fan. Clients: tablet heading above grid; mobile three columns, five rows. Projects: mobile all single column, every-third spans reset, 40px section header gap. Services: mobile retains two columns and reorders to Estratégia/Branding, Web Design/Interfaces, Design System/Motion, Consultorias/UI & AI; descriptions hidden. Statistics: below 1200 offsets disabled, below 810 two by two cards, 16px padding and 156px card height. Testimonial: mobile photo hidden and quote panel fills width. FAQ: mobile help column hidden, questions span width; first answer remains open. Blog: four desktop, three tablet, two mobile; mobile heading Blog Wama and summaries hidden. Contact: mobile centered max 480px, one column; shorter intro, labels and inputs preserved. Footer: links wrap to narrow layout with a large wordmark; no horizontal page overflow.
